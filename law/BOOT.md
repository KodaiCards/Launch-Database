## Environment + spawn rules (Carter 2026-07-03 — usage protection)
- **No heavy environment setup in worker sessions.** Never `playwright install` / browser downloads / global installs. **`npm run premerge` (Playwright) runs ONLY on the Registrar's persistent environment** — foremen/VOs never run it themselves. `npm ci` only when your package actually requires a build; content-only packages (prose, pools, JSON) need NO install — edit + grep + commit.
- **Spawns NEVER inherit your model.** Task-tool subagents default to the parent's model — ALWAYS set the model explicitly per the loadout (Sonnet 5 for judgment-bearing subtasks, Haiku 4.5 for mechanical). An unset spawn model is a law §5 violation.
- **STALE/DEAD SESSION PROTOCOL (Carter 2026-07-03): a stalled session is ALWAYS replaced, never resumed.** Stalls are normal (errors, lost access, limits, mid-work pauses); resuming one is both expensive (cold cache re-bills its whole context — observed 25% of a bucket on one "Continue") and unreliable. Kill it; boot a fresh session on the SAME slot template.
  - **Banking cadence (what makes replacement lossless):** workers push a WIP commit to their branch at EVERY increment — the commit message carries state ("WIP: T02 prose done; RT NOT started"). Comment the issue at claim, at each step boundary, and the INSTANT anything blocks. **If gh dies but git works, the WIP commit message IS your status channel — push it.** If both die, print a HANDOFF block in chat for Carter to relay. Unbanked work older than one increment should not exist.
  - **Successor recipe:** boot fresh → poll shows your own claimed:f‹N› issues → read the issue comments + `git log` of the branch INCLUDING WIP messages → **verify the claimed state against the actual files (never trust the corpse's last words — a step with no artifact gets redone)** → comment "RESUMED f‹N› @ <sha>: <state summary>" → continue mid-stride.
- Playthroughs when your environment can't run the app: state it plainly in your `built` comment ("playthrough deferred to VO — no runtime here"); the VO/Registrar playthrough covers it. Never fake a playthrough.
