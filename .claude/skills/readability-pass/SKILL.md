# Readability pass (procedure for law/PRODUCT_BAR.md §1 — the law; read it first)

**Audience:** inspectors dualing as engineers-in-training. Zero prior OSP knowledge at T01; exactly what earlier lessons taught after that. You are teaching a person, not filing a compliance memo.

## ⛔ The anti-ratchet warning (read twice)
This is a READABILITY pass. The citation gate already passed. **Do NOT add citations, hedges, qualifiers, or bracketed notes to prose.** Only a changed FACTUAL CLAIM reopens citation review. The last regime turned a "make it easier to read" request into MORE citation density — that failure mode is why this skill exists.

## The transform, per code/standard mention in body prose
Rewrite to the four-beat pattern (Carter's formula, law):
> "This is **NESC code XXX** — it states **XXX** — we use this in **XXX** because it helps us do **XXX**."
Then move the exact citation string (section number, form number, CFR ref) OUT of the sentence and INTO the lesson's **References block** (shared component from issue #46). Body prose keeps the plain-English name ("the NESC clearance rule"), the References block keeps "NESC C2 Rule 232".

## Checklist per lesson
1. Natural names only, everywhere a trainee looks: no T0x/L0x, no "research log", no "red-team", no pipeline vocabulary. Cross-refs by lesson NAME ("see the Underground Conduit lesson").
2. One idea per paragraph; new terms defined at first use in words a new hire knows; an analogy or field scenario per concept where one fits.
3. Builds only on prior lessons — if it needs something not yet taught, teach it inline or flag a `deviation`.
4. Assessment text: no question requires recalling a code NUMBER. Test the practical use ("which rule governs this situation and what does it make you do?"), never the digits. Swap recall questions using the pool's existing research base — pool size must stay ≥ draw count.
5. Answer explanations read clean standalone — plain reference form ("per the NESC clearance rules") is fine; internal vocabulary is not.

## Self-test before flipping built
Read the lesson as a brand-new hire. Ask: *could I tell someone why this matters on a jobsite?* If any paragraph just throws facts, rewrite it. Then TAKE the assessment start-to-finish — reading it is not taking it.
