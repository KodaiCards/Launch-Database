## Negative Findings (checked + confirmed clean)

- **All `pool.connect()` sites have `client.release()` in `finally` blocks** — checked all 35 sites in `splice.js`, `billing.js`, `admin.js`, `contracts.js`, `hours_csv.js`, `ai.js`, `projects.js`, `timeclock_module.js`. No naked `pool.connect()` without matching `finally { client.release() }`.
- **SSE clients are properly removed on `req.on('close')`** — `_removeSseClient` called in close handler and both pingTimer branches. No SSE client leak.
- **`_pendingApprovals` cleanup timer is set with `.unref()`** — won't block process shutdown. TTL is 15 min with 5 min sweep.
- **`_broadcast` try/catch** — dead connections are swallowed, not leaked into the Set (Set is pruned on `req.on('close')`). No accumulation.
- **Contractor share-link HTML file** — already converted to `fs.promises.readFile` (async) per DISCOVERY item 3. Confirmed at `splice.js:2800`.
- **`collectProjectTree`** — single recursive CTE, no loop. Clean.
- **`GET /api/projects`** — bounded with LIMIT 1000 default. Clean.
- **`admin.js` sync fs** — all blocking calls converted except `statfsSync` (intentional kernel stat, no disk I/O). Clean.
