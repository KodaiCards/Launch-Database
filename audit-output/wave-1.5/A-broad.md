# Wave 1.5 Remainder — Auditor A (broad fresh-eyes)

## Stack snapshot (≤80 words)

Express + Postgres + Puppeteer (invoice_template_engine.js, routes/splice.js). Auth via JWT cookie + Bearer header fallback; `tokens_invalid_after` enforced in authMiddleware and both SSE heartbeats. ~18 route files use the `(mw && mw.requireAuth) || (() => (req,res,next) => next())` defensive pattern; several are mounted with `{}` mw. Schema.sql contains a conflicting `ALTER TABLE` that overwrites a deliberate RESTRICT FK with CASCADE.

## Negative findings

- **Puppeteer SSRF scope**: `invoice_generator.js` (RUS invoice PDF) does NOT use Puppeteer — uses PDFKit only. No SSRF surface there. Clean.
- **Splice SSE JWT iat re-validation**: `routes/splice.js` lines 3501-3527 correctly captures `sseTokenIatSec = req.user.iat` at connect time and re-validates against `tokens_invalid_after` on every 25-second heartbeat. Clean.
- **`routes/_sse.js` SSE iat re-validation**: Lines 169-195 correctly re-validates `tokens_invalid_after` vs `meta.tokenIssuedAt` on each heartbeat tick. `req.user.iat` is propagated by `authMiddleware` (auth.js:286). Clean.
- **JWT audience pinning**: `signToken` at auth.js:232 includes `audience: JWT_AUDIENCE`; `verifyToken` at auth.js:241 enforces `audience: JWT_AUDIENCE` with `algorithms: ['HS256']`. Clean.
- **Permit actor bypass**: `routes/permits.js` lines 46-54 and 84-90 explicitly source actor from `req.user.full_name || req.user.username`. `req.body.actor` removed. Clean.
- **design_pipeline.js actor bypass**: line 97 comment confirms body-actor fallback removed. Verified line 97 sources from `req.user`. Clean.
- **requireAuth empty-array trap**: `auth.js` line 303 has the Item 20 fix: `allowed && allowed.length > 0 && !allowed.includes(role)` correctly passes through on empty array. Clean.
- **Splice catch blocks leaking error.message**: Sampled 20+ catch blocks across splice.js; all return generic fixed-string error messages (e.g., `'Failed to add cable.'`) not `e.message`. Clean.
- **Empty catch blocks in splice.js** (non-SSE): All bare `catch {}` are in `finally`/cleanup branches (ROLLBACK, browser.close, res.end) where swallowing is intentional and safe.
