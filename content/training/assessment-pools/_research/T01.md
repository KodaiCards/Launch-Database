## Verification method

Live document fetch (WebFetch) to primary sources (usda.gov, ecfr.gov, ieee/ansi storefronts,
wikipedia.org) returned **HTTP 403 from the org egress proxy** for every host tried — a policy
denial, not a transient failure (confirmed via `/root/.ccr/agentproxy/status`; no relay failures
logged, so the block is intentional org policy, not a bug to route around). WebSearch (a separate
tool) was reachable and used instead: each citation below was checked against multiple independent
result snippets (official .gov mirrors, standards-body storefronts, and/or trade-press summaries)
for **topical scope and correctness of standard/section identity**, not full-text clause wording —
full-text of NESC/TIA/ICEA/ANSI is paywalled and not obtainable via search snippets. Where an exact
sub-clause number could not be independently confirmed, the pool question avoids relying on that
number, or the number is flagged below as **UNVERIFIED-EXACT** (same hedge convention the existing
lesson prose already uses: "[confirm edition]" / "verify before design lock").
